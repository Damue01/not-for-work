# 今天适合上班吗？

纯静态网页。MBTI、星座、生肖、八字、塔罗牌和抽签的结果均为「不适合上班」。

## 本地打开

解压后，直接打开 `index.html`。无需安装依赖、构建或服务器。

## GitHub + Cloudflare Pages

1. 将 `index.html`、`style.css`、`script.js` 和 `assets` 文件夹 放在 GitHub 仓库根目录。
2. 在 Cloudflare Pages 中连接该仓库。
3. 使用静态 HTML 配置：不需要构建命令，输出目录为仓库根目录。

也可将以上文件和文件夹直接上传至支持静态网页的托管服务。

无后端、无外部资源、无统计脚本、无数据收集。

八字为娱乐交互，不进行命理计算；日期可留空，时辰可选“不清楚”。出生信息不会读取、储存或发送，提交或离开时自动清空。塔罗牌在本地随机抽牌，单击所选牌立即翻开，随后自动显示结果；抽象几何牌面为原创设计，不提供牌义解读。MBTI 为两道简短二选一问题，不推断人格类型。支持键盘和减少动态效果的系统偏好。
